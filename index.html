DocBuilder Quick Start Guide

  • 1. Build Pages & Rows: Click + New Page in the top tab bar to add sections, and click + Add Row in the left Build menu to insert a 12-column grid container. Use a row's ⚙️ button to adjust column layouts and vertical spacing.
  • 2. Drag Content Blocks: Drag Text, Image, Slideshow, Button Link, or Spacer / Line blocks from the Build zone into any row slot. Blocks displaced during column layout changes are automatically saved to the Docking Tray.
  • 3. Manage Libraries: Use Asset Library to manage deduplicated project images and Email Templates to build interactive mailto: cards.
  • 4. Document Design & Export: Open Document Design to switch between Standard Document and 16:9 Presentation Deck modes, choose Left Sidebar or Bottom Floating Dock navigation, customize typography/colors/CSS, and export via File → Export Document (HTML).
💡 Need Diagnostics or Test Data?
Open Workspace Settings (⚙️) → Developer & Diagnostics to load the Master Test Document or run storage maintenance.
